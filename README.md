# 🦊 Vulpine Agentic System

*A cunning framework for intelligent reasoning, critical thinking, and decision-making under uncertainty.*

---

## What is Vulpine?

Vulpine is an agentic reasoning architecture that guides AI systems (and humans) through structured critical thinking. Named after the fox's legendary cunning, Vulpine operates on a simple principle:

> **Think like a fox: question everything, consider alternatives, verify twice, act once.**

Rather than generating fast answers, Vulpine generates *defensible* answers by forcing rigorous reasoning at each stage.

---

## Core Architecture: The Five Dens

Vulpine breaks down complex reasoning into five cognitive stages:

### 🔍 **Den 1: The Perception Warren**
Problem decomposition, assumption surfacing, constraint mapping. *What are we actually being asked?*

### 🌳 **Den 2: The Reasoning Forest**
Multi-path exploration with intelligent pruning. *What are all the ways to think about this?*

### ⚖️ **Den 3: The Verification Burrow**
Consistency checking, evidence integrity testing, sensitivity analysis. *What could prove us wrong?*

### 🧩 **Den 4: The Synthesis Lodge**
Structured articulation, confidence calibration, hedging. *What can we confidently say?*

### 🎯 **Den 5: The Reflection Pool**
Pattern extraction, heuristic filing, learning loops. *What do we take forward?*

### Quick Example

**Question:** Should we deploy this feature?

**Vulpine Process:**
1. **Perception Warren** — Strip away marketing language. Real question: Is risk/reward acceptable?
2. **Reasoning Forest** — Deploy now? Wait? Gradual rollout? Abort? Score each path.
3. **Verification Burrow** — Test assumptions about metrics, load, dependencies. Identify breaking points.
4. **Synthesis Lodge** — "Deploy with monitoring, 7.5/10 confidence. Biggest risk: load handling (4/10)."
5. **Reflection Pool** — File heuristics: Edge case patterns more predictive than metrics alone.

**Result:** Defensible decision. Clear reasoning. Honest uncertainty. Reusable patterns.

## Why This Works

Unlike traditional reasoning frameworks (which are often prescriptive flowcharts), Vulpine is **descriptive of how reasoning actually happens**:

- **Humans decompose problems** (Den 1) before exploring solutions (Den 2)
- **Good thinkers test their reasoning** (Den 3) before committing to conclusions (Den 4)
- **Experts learn from cases** (Den 5) and apply patterns to new problems
- **Real reasoning is iterative**, not linear — the dens can loop back

Vulpine formalizes this natural process and makes it explicit, repeatable, and improvable.

## The Fox's Reasoning Heuristics

Vulpine includes a library of reasoning patterns:

- **Pattern Recognition** — Identify problem class, map to proven solutions, flag novel elements
- **Causal Chains** — Trace root causes, distinguish correlation from causation, map downstream effects
- **Probabilistic Thinking** — Bayesian updating, base rate consideration, rare event awareness
- **Inversion** — Assume opposite conclusion, reverse-engineer from desired outcome, "what would make this fail?"
- **Constraint Mapping** — Identify hard constraints (deal-breakers), soft constraints (preferences), hidden constraints

See [CRITICAL_THINKING_ARCHITECTURE.md](./CRITICAL_THINKING_ARCHITECTURE.md) for full heuristic library and configuration options.

## Configuration

Vulpine's thinking style is tunable:

```yaml
reasoning_depth: 5              # How many levels of analysis?
path_exploration: 5             # How many alternatives to explore?
confidence_threshold: 0.7       # Act only if confidence ≥ threshold
hedge_ratio: 0.3                # Balance certainty vs. nuance
paranoia_level: 7               # How aggressive with assumption checking?
pattern_memory: 500             # How many past patterns retained?
```

Adjust these knobs based on your domain and risk tolerance.

## How to Use Vulpine

### For Humans
1. Pick a question or decision you're uncertain about
2. Work through the Five Dens systematically
3. Document your assumptions, evidence, and reasoning chains
4. Calibrate confidence honestly (not as 1/10 but *why* 1/10)
5. Extract patterns for future use

### For AI Agents
1. Implement the Five Dens as separate reasoning stages
2. Use constraint satisfaction to prune low-viability paths early
3. Build linguistic markers detection for deception/opacity
4. Maintain confidence scores, not binary outputs
5. Log heuristics to strengthen future reasoning
